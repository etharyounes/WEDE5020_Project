# GreenSprout Community Garden NPO - Comprehensive Project (Part 3)

##  Project Overview
The GreenSprout Community Garden website is a community-driven platform designed to promote sustainable urban gardening, educational workshops, local volunteer opportunities, and sponsor engagements. This repository contains the final deliverables for **Part 3**, combining the foundational structure (Part 2) with advanced JavaScript interactivity, robust form validations, and comprehensive Search Engine Optimization (SEO).

---

##  Changelog & Version History

### **Part 2: Foundational Website Development**
- **Core Structure:** Built semantic HTML5 layout structures across primary pages (`index.html`, `about.html`, `services.html`, `enquiry.html`, and `contact.html`).
- **Styling & Design:** Implemented responsive CSS styles (`style.css`) to ensure optimal user experience across multiple screen resolutions.
- **Asset Management:** Integrated custom graphical assets and organized project file directory structures.

### **Part 3: Enhancements, Functionality & SEO (Current Release)**
- **Interactive JavaScript Enhancements (`script.js`):**
  - Developed an interactive image gallery with a **Lightbox** feature, allowing users to click and view high-resolution garden images in a modal overlay.
  - Implemented a **Dynamic Search Filter** to allow real-time filtering of content and services based on user input.
- **Advanced Form Validation & Processing:**
  - **Enquiry Form (`enquiry.html`):** Integrated strict client-side field validation, dynamic cost estimation, and automated success/error response handling.
  - **Contact Form (`contact.html`):** Added comprehensive validation rules with automated data compilation and secure `mailto:` redirection for sending direct messages to the organization.
- **Search Engine Optimization (SEO):**
  - **On-Page SEO:** Added descriptive title tags, meta descriptions, semantic header structures, and optimized alt texts for all graphical elements.
  - **Technical SEO:** Created and configured a professional `robots.txt` file to guide web crawlers and a detailed `sitemap.xml` mapping the complete site architecture.
- **Deployment & Documentation:**
  - Deployed the finalized web application live via **GitHub Pages**.
  - Documented all changes and code implementations thoroughly within the repository.
